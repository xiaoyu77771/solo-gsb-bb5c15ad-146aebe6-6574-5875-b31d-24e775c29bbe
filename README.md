# 字幕节奏校对台（Subtitle Rhythm Deck）

一个完全在本地 / 浏览器内运行的字幕时间轴校对工具：导入 **SRT 字幕** 与**浏览器可播放的音频**，
在同一时间轴上拖动字幕块的左右边界校准节奏。拖动时实时强制 **不重叠 / 最短时长 / 最小间隔** 三条约束，
越界操作会**自动回弹并标出原因**。

- React 18 + TypeScript + Vite，纯前端、无后端、无外部服务
- 字幕与音频均通过浏览器本地读取，**不会上传任何文件**
- Nginx 静态镜像 + Docker Compose 一键启动

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 导入 SRT | 兼容 `,` / `.` 毫秒分隔符、缺序号块、CRLF；解析异常逐块告警不中断 |
| 导入音频 | 任意浏览器原生可播放格式（mp3 / wav / m4a / aac / ogg / opus 等） |
| 本地静音分析 | 音频加载后用 **Web Audio API** 本地解码（不上传），按 **20ms 窗口**计算各声道 RMS 的最大值；低于可调阈值且连续 **≥200ms** 才形成静音段，间隔 **<80ms** 的段先合并 |
| 静音带叠加 | 静音段以斜纹带叠加在标尺与泳道上，拖动吸附命中的段会高亮 |
| 静音吸附 | 拖动字幕边界进入静音段边缘 **150ms** 范围即吸附到最近边缘，两侧等距取更早者；吸附结果仍须通过最短时长 / 最小间隔校验，不合法时**保留未吸附候选并提示原因**；工具栏提供吸附开关与可调阈值（dB） |
| 时间轴校对 | 拖动字幕块**左/右边界**手柄调整起止时间，毫秒级吸附（1ms） |
| 三重约束 | 实时校验：不可与相邻字幕重叠、不短于「最短时长」、不小于「最小间隔」、不可越过 0s |
| 越界回弹 | 非法位置松手后块原样回弹，显示红色虚影 + 气泡说明具体原因（与上/下一条、差多少毫秒） |
| 约束参考线 | 拖动时黄色虚线标出当前边界允许的活动区间 |
| 点击定位播放 | 点击字幕块或列表中的时间码即跳转并播放；点击标尺/空白轨道定位播放头 |
| A-B 循环试听 | 以选中字幕起止 ± 可调前后余量形成循环区间，播放越过 B 点自动回到 A 点；切换选择保留开关并更新区间，播放头落在新区间外立即跳到新 A 点；时间轴标出 A/B 旗标与循环范围；无音频 / 未选字幕 / 区间裁剪后为空时禁用并说明原因 |
| 撤销 / 重做 | 仅记录成功的边界调整；`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z`（或 `Ctrl+Y`）重做 |
| 缩放 | 滑块在 10–400 px/s 之间无级缩放，横向滚动浏览 |
| 约束可调 | 工具栏实时修改最短时长与最小间隔（秒），立即对后续拖动生效 |
| 导出 SRT | 按时间先后重排并输出连续编号 `1..N`，文件名为 `<原名>.fixed.srt` |

> 说明：本工具专注「节奏」校对，即只调整时间码，不编辑字幕文本。

## 一键启动（Docker Compose）

需要 Docker 20.10+ 与 Compose v2。

```bash
docker compose up -d --build
```

启动后访问：

```
http://localhost:8080
```

停止：

```bash
docker compose down
```

### 配置

| 配置项 | 方式 | 默认值 |
| --- | --- | --- |
| 宿主机访问端口 | 环境变量 `SUBTITLE_PORT`（compose 自动插值） | `8080` |

换用 9090 端口的示例：

```bash
SUBTITLE_PORT=9090 docker compose up -d --build
# 访问 http://localhost:9090
```

容器内固定监听 80，由 Nginx 托管构建产物；无数据卷、无账号、无网络外发。

## 使用步骤

1. 打开页面后点击 **导入 SRT**，选择字幕文件（解析告警会出现在右下角）。
2. 点击 **导入音频**，选择与字幕配套的音频。加载后会自动用 Web Audio API 解码并检测静音段（状态栏显示「静音分析中… / N 段静音」）；**更换音频会取消旧分析，旧结果不会回写**。
3. 用滑块调整合适缩放；鼠标悬停边界手柄可看到允许拖动范围。时间轴上的斜纹带即静音段。
4. 按住字幕块的**左/右手柄**拖动：
   - 边界进入静音段边缘 **150ms** 内时自动吸附（绿色吸附线 + 气泡），两侧等距取更早边缘；
   - 吸附点若违反最短时长 / 最小间隔 / 重叠约束，则**不采用吸附**，保留未吸附候选，并以气泡与提示条说明原因；
   - 合法位置松手 → 边界更新并进入撤销历史；
   - 非法位置松手 → 块回弹，红色虚影与气泡标明原因（重叠 / 间隔不足 / 时长不足 / 越过 0s）。
5. 工具栏可勾选/取消 **静音吸附** 开关，并用 **阈值（−60 ~ −20 dB）** 滑块调整静音判定电平；调阈值只对当前音频重新分段，无需重新解码。
6. 点击字幕块本体或左侧列表时间码，播放头跳到该字幕并开始播放。
7. 选中一条字幕后可开启工具栏的 **A-B 循环**：循环区间为「字幕起点 − 前余量 → 字幕终点 + 后余量」（余量可实时调整，A 不越过 0s、B 不越过音频结尾）；播放越过 B 点自动回到 A 点继续。切换选择时循环开关保留、区间随之更新，播放头落在新区间外会立即跳到新 A 点；暂停、导入新音频或关闭循环后，旧的播放回调不会再拉回播放头。未导入音频、未选字幕或区间经音频时长裁剪后为空时，开关禁用并显示原因。
8. 快捷键：`空格` 播放/暂停，`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z` 重做。
9. 点击 **导出 SRT**，得到按时间顺序重新编号的校对结果。

## 静音检测与吸附的精确定义

- **窗口能量**：解码后按 `20ms` 窗口遍历，对每个声道计算 RMS，窗口能量取**各声道 RMS 的最大值**（任一声道有声即不算静音）。
- **成段条件**：窗口能量**严格低于**阈值的连续窗口形成候选段；连续时长 **≥ 200ms** 才保留（恰好 200ms 合法）。
- **段合并**：两个候选段之间的非静音间隔 **< 80ms** 时先合并为一段（恰好 80ms 不合并），合并后再过最短时长过滤。
- **吸附规则**：边界原始候选时间 `t` 在某静音段边缘（段起点或段终点）**150ms 半径内**（严格小于）才吸附；取距离最近的边缘，距离相等时取时间更早者。
- **吸附校验**：吸附后的时间必须与未吸附候选走**同一套**约束校验（不重叠 / 最短时长 / 最小间隔 / ≥0）。吸附点合法则采用吸附；吸附点不合法则保留未吸附候选，并返回吸附点的具体违规原因。

## A-B 循环的精确定义

- **区间**：`A = max(0, 字幕起点 − 前余量)`，`B = min(字幕终点 + 后余量, 音频时长)`（时长未知时不裁剪 B）；余量负值按 0 计；`B − A < 0.05s` 视为空区间，循环不可用。
- **回卷**：循环激活且播放中，帧级监听发现 `currentTime ≥ B` 即跳回 A 继续播放；B 恰好等于音频结尾时由 `ended` 事件回卷。
- **进入**：开启循环或切换选择时，播放头落在 `[A, B]` 之外立即跳到新 A 点（保持当前播放/暂停状态）；落在区间内则不移动；仅调整余量不抢播放头。
- **失效**：暂停、导入新音频、关闭循环都会同步作废旧循环计划并取消帧监听，此后任何已排队的播放回调都不会再改动播放头。
- **禁用**：无音频、未选字幕、区间经音频时长裁剪后为空，三者任一成立即禁用开关并显示原因；已开启的循环进入待机，条件恢复后自动续用。

## 约束规则的精确定义

设被调整字幕为 `C`，时间轴上相邻的上一条为 `P`、下一条为 `N`：

- 拖动左边界到 `s` 时必须满足：
  `s ≥ 0`、`s ≤ C.end − 最短时长`、
  `P` 存在时 `s ≥ P.end + 最小间隔`（该条件同时排除了重叠）。
- 拖动右边界到 `e` 时必须满足：
  `e ≥ C.start + 最短时长`、
  `N` 存在时 `e ≤ N.start − 最小间隔`。
- 任一条件不满足则不修改数据（回弹），并返回第一条被违反规则的说明。

    ├── main.tsx

    ├── types.ts
    ├── styles.css
    ├── components
    │   ├── Toolbar.tsx     # 导入/走带/缩放/约束/吸附开关与阈值/撤销重做/导出

        ├── srt.ts          # SRT 解析 / 序列化 / 时间格式化
